# Sample projects

Samples of the [project file](../../../core/docs/spec/project-file.md), for every implementation of the format.

- `single-file.json` and `folder/` hold the same content in the two shapes.
- `unknown-tool` is a section no standard reader knows, and `folder/unknown-folder` is a sub-folder none knows.

A reader must read each sample and write it back without loss, and the two shapes must give the same content.
