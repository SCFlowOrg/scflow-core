# @scfloworg/mcp

An MCP server on the workspace: an MCP client works on one project on disk through its actions, finds the skills of the installed modules as MCP prompts, and reads their documentation topics through `search_docs`, `read_docs` and MCP resources.

```text
scflow-mcp <project> [--modules <folder>]
```

See [docs/mcp.md](docs/mcp.md).
